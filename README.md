# MetaTana Support

This is the support home for **MetaTana** — an AI-powered local media manager. Drop a folder, and
MetaTana identifies your content, fetches artwork and metadata, and organizes your library.

This repository holds no code. It exists so there is one public place to ask questions and report
problems.

## Get help

**[Open a Discussion →](https://github.com/metatana/support/discussions)**

Before posting, the docs answer most questions:

- [Installation](https://metatana.com/docs/getting-started/installation)
- [Docker](https://metatana.com/docs/getting-started/installation/docker)
- [Unraid](https://metatana.com/install/unraid)
- [Desktop (macOS, Windows, Linux)](https://metatana.com/docs/getting-started/installation/desktop)
- [All documentation](https://metatana.com/docs)

## Reporting a problem

A good report gets a fast answer. Please include:

- **Version** — shown in Settings, or the image tag for Docker
- **How you installed** — desktop app, Docker, Unraid, TrueNAS
- **Platform** — macOS, Windows, Linux, or your NAS
- **What you expected**, and **what happened instead**
- **Logs**, if you have them

Redact anything private before pasting. Logs can contain file paths.

## Security issues

Please do **not** open a public Discussion for a security vulnerability.

Use [private vulnerability reporting](https://github.com/metatana/support/security/advisories/new)
instead. Only MetaTana maintainers can see it.
