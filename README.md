# MetaTana Support

This is the support home for **MetaTana**. It turns the movie, TV, and anime folders you already own
into a clean, complete media library. Add a folder and MetaTana identifies each title, fills in
metadata and artwork, and shows you the result before anything moves.

This repository holds no code. It exists so there is one public place to ask questions and report
problems.

## Get help

**[Open a Discussion →](https://github.com/metatana/support/discussions)**

Discussions keep answers searchable and help the next person too.

Before posting, the docs answer most questions:

- [Installation](https://metatana.com/docs/getting-started/installation)
- [Docker](https://metatana.com/docs/getting-started/installation/docker)
- [Unraid](https://metatana.com/install/unraid)
- [Desktop (macOS, Windows, Linux)](https://metatana.com/docs/getting-started/installation/desktop)
- [All documentation](https://metatana.com/docs)

## Reporting a bug

Use the **[private MetaTana bug form](https://metatana.com/support#report-a-bug)** for the normal path. It gives you a MetaTana ticket number and email updates. Reports stay private while they are checked.

Technical users can also open a **[public GitHub bug report](https://github.com/metatana/support/issues/new/choose)** when the full report is safe to share. GitHub issues are public. Do not include email addresses, file paths, library names, logs, account details, or anything else private.

## Security issues

Please do **not** open a public Discussion for a security vulnerability.

Use [private vulnerability reporting](https://github.com/metatana/support/security/advisories/new)
instead — only MetaTana maintainers can see it.
